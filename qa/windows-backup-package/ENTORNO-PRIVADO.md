# Alternativa sin ASUS

No ejecutamos ni creamos un entorno remoto, ni comprobamos facturacion/cuotas de tu cuenta. Por eso no certificamos hoy una alternativa remota simultaneamente disponible, gratuita y segura para tus datos. La opcion preferida sigue siendo equipo privado bajo tu control.

Una opcion CONDICIONAL es un GitHub Codespace privado temporal, con Node 24, Python y Docker local. El plan personal Free incluye una cuota de uso (120 core-hours y 15 GB-mes segun documentacion consultada); el almacenamiento consume cuota mientras se conserva el Codespace, aunque este detenido. Sin metodo de pago GitHub bloquea al agotar cuota; con tarjeta puede generar cargos. El propietario debe verificar ausencia de metodo de pago y saldo gratuito ANTES de crear nada. No agregues tarjeta ni amplíes presupuestos para este procedimiento. No sirve una organizacion con facturacion heredada o garantias no comprobadas.

Procedimiento futuro, solo tras autorizacion de captura real: abrir un Codespace de repositorio PRIVADO sin secretos en Git, sin extensiones/tasks no confiables y sin puertos publicos/compartidos. Confirmar privacidad, cuota y cobro bloqueado en Billing. Copiar el contenido limpio del ZIP, sin subir archivos de custodia a Git. Ejecutar primero `node --test package-tests.mjs` y `node laboratorio.mjs` con CLI 2.121.0 verificada (ver SHA en INICIAR.ps1 y workflow QA). Docker debe ser local; no contextos remotos. El runner Actions NO es sustituto privado: captura real bloqueada alli.

`python3 PRIVADO.py verificar` comprueba archivos cifrados existentes; `python3 PRIVADO.py respaldar` pide datos en entrada oculta y verifica precondiciones. Node 24 y Docker son requisitos; el script no provisiona servicios. Usa `getpass`, stdin privado y unicamente captura de lectura; no pega secretos en shell, historial, archivos .env ni variables persistentes. Las ubicaciones de respaldo y clave deben ser separadas y fuera del repositorio. Los recibos y el inventario privado se preparan como describe COBERTURA-Y-RECUPERACION.md. La declaracion de cuota/privacidad es atestacion humana: el script no puede certificar tu facturacion.

Descargar SOLO respaldo y clave cifrados a custodias separadas; comprobar ambas copias y frase fuera del entorno antes de destruirlo. No puede cumplirse custodia durable si solo quedan los archivos en el Codespace. Borrar el Codespace completo tras verificar las copias; no dejarlo detenido consumiendo almacenamiento. No subir respaldos, claves ni registros privados a Actions/artifacts/cache/GitHub Issues. No abrir puertos de Auth/DB/Storage a internet. Datos claros siguen existiendo en RAM y volumen temporal del proveedor; esta opcion exige confiar en su aislamiento y politica de borrado, no ofrece control fisico local.

Si no puedes verificar cada condicion, NO-GO remoto gratuito. Esperar la ASUS es mas seguro y economico que improvisar runners compartidos o servicios con tarjeta. Desde el celular solo podes descargar/conservar el ZIP limpio ahora; no hace falta introducir accesos.
