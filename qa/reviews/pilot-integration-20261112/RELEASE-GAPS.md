# Bloqueos reales conservados

| Bloqueo | Evidencia necesaria / siguiente responsable |
|---|---|
| Primera propiedad | Productor protegido pre-property y fuentes de fundador/owner/cuenta/cupo/CABA/revisiones/floors; admisión y original confiables. Se conserva el cierre property-producer-gates, sin repetir su búsqueda. |
| Native17 | Host PostgreSQL 17.11 exacto con aislamiento/recursos/descarte acreditados y autorización específica por artefacto/ensayo. N01–N12/BPF siguen no autorizados. No se infirió resultado del diagnóstico ASUS independiente. |
| Auth | Verificación real del proveedor, sesión/revocación/refresh y operaciones concurrentes. Las respuestas sintéticas de UI no son JWT verificados. |
| Writer/reader/journal | Puertos/roles efectivos mínimos, original durable, admisión NEW/KNOWN, COMMIT externo y reader independiente con journal/witness. No convertir ACK COMMITTED en éxito ni UNKNOWN en nuevo intento. |
| Privacidad/legal | Decisiones específicas de finalidad, acceso, custodia y retención D02-A; publicación legal/prelegal y permiso comercial. No almacenar nuevos datos ni secretos para simplificar conciliación. |
| A2 | Recuperación PostgreSQL + Auth/GoTrue + Vault + Storage + configuración/claves + revocaciones/journal/witness/floors posteriores al backup. Se reutiliza inventario anterior; no restore ejecutado ni permisos recuperados desde backup antiguo. |
| Navegador | Laboratorio compatible y seguro para casos existentes y BFCache/CORS real. AF_UNIX/EPERM no se reintentó. |

Ninguna de las once mutaciones históricas fue habilitada. Crear/configurar propiedad, estadía, asociación huésped, cancelación, checkout y alta/invitación comerciales continúan retenidos. Las instrucciones futuras de activación/reversión del candidato previo siguen siendo descriptivas y no se ejecutaron. Este lote no introduce instalador ni mecanismo de activación.
